# 坦克大战 (Tank Battle)

经典坦克对战游戏的 HTML/Canvas 实现，纯前端，无需任何依赖，打开浏览器即可游玩。

> 可直接打开 `index.html` 在浏览器中运行。

## 操作说明

| 按键 | 功能 |
|------|------|
| **W/A/S/D** 或 **方向键** | 移动坦克 |
| **空格键** | 射击 |
| **Q** | 护盾技能（10秒冷却，3秒无敌） |
| **E** | 强力射击（8秒冷却，3倍伤害） |
| **P** | 暂停/继续 |
| **重新开始按钮** | 重置游戏 |

## 功能特性

### 💎 RPG 系统

#### 经验值与升级
- 击杀敌人获得经验值（EXP）：普通敌人 10 EXP，精英 20 EXP，Boss 30 EXP
- 经验值满自动升级，全屏粒子特效
- 每升一级提升最大 HP，每 2 级提升攻击力，每 3 级提升防御力
- 画布左上角实时显示 HP 条、EXP 条和当前等级

#### 玩家属性
- **HP**：初始 3 点，升级增加。受到伤害先扣 HP，归零才死亡
- **攻击力（ATK）**：影响子弹伤害，基础攻击 + 武器加成
- **防御力（DEF）**：减免所受伤害（`damage - DEF`，最少 1 点），基础防御 + 护甲加成
- 生命耗尽后消耗一条命，在安全位置重生并回满 HP（带短暂无敌护盾）

#### 装备掉落系统
- 击杀敌人有 65% 概率掉落物品，接近自动拾取：
  - **恢复包**（绿色）：恢复 2 HP
  - **攻击强化**（红色）：10 秒内攻击 +2
  - **速度强化**（蓝色）：10 秒内移速 +0.5
  - **护盾**（金色）：5 秒内无敌
  - **武器升级**（红色掉落）：5 种武器 — 基础炮管、速射炮、重型炮、狙击炮、散弹炮
  - **护甲升级**（紫色掉落）：4 种护甲 — 布甲、轻甲、重甲、板甲
- 武器影响攻击力和射速，护甲提供伤害减免
- 掉落物带浮动发光动画，拾取时有粒子特效和浮动文字提示

#### 主动技能
- **护盾（Q）**：10 秒冷却，3 秒无敌，全身发光护盾
- **强力射击（E）**：8 秒冷却，发射红色发光子弹，3 倍伤害、1.5 倍速度
- 画布底部显示技能栏和冷却倒计时

#### Buff 系统
- 拾取 Buff 道具后，画布上方显示持续时间
- 同类 Buff 拾取自动延长持续时间

### 核心玩法
- 多关卡设计，每关需消灭全部 10 辆敌方坦克方可进入下一关
- 随关卡提升，敌人生成速度加快，地图布局更复杂
- 玩家拥有 3 条生命，阵亡后回满 HP 并在安全位置重生（带短暂无敌护盾）

### 敌人 AI
- 敌人自主巡逻、追逐玩家
- 60% 概率朝玩家方向移动，40% 概率随机移动
- 智能射击：面朝玩家方向时优先开火
- 碰撞后自动切换方向

### 坦克类型
- **玩家坦克**（绿色）：速度较快，射速高，带 RPG 属性
- **普通敌方坦克**（红色）：标准属性，10 EXP
- **中型敌方坦克**（橙色，Lv2+）：2 点生命值，20 EXP
- **重型敌方坦克**（紫色，Lv3+）：3 点生命值，带血条显示，30 EXP

### 子弹系统
- 玩家子弹速度更快（5px/frame），可弹射墙壁一次
- 敌方子弹速度较慢（3.5px/frame）
- 敌我子弹可对撞抵消
- 子弹带有拖尾特效
- 强力射击为红色发光子弹，伤害 3 倍

### 地图系统
- **砖墙**（红色）：2 点生命值，可被子弹击碎，受损后显示裂纹
- **钢墙**（灰色）：不可摧毁，带铆钉装饰
- 5 种预设关卡布局 + 随机散落墙壁，每关体验不同
- 布局包括：横排墙、方格堡垒、十字阵列、散点网格、钢铁要塞

### 视觉特效
- 爆炸动画（由内向外扩散 + 白色高亮核心）
- 粒子系统（击中墙壁、坦克爆炸、得分、拾取道具等场景）
- 屏幕震动（坦克爆炸时）
- 子弹拖尾光晕
- 坦克履带细节绘制
- 护盾闪烁效果（重生无敌期间）
- 物品掉落浮动发光动画
- 浮动文字提示（升级、拾取、装备变更）
- 半透明暂停/胜利/失败遮罩

### HUD
- 画布左上：HP 条（颜色随血量变化绿→黄→红）+ EXP 条 + 等级
- 画布右上：当前攻击力 / 武器名 + 防御力 / 护甲名
- 画布底部：技能栏带 CD 倒计时
- 画布上方：Buff 持续时间指示器
- 右上角：分数、剩余敌人数量

### 其他
- 关卡通过时显示胜利提示，2 秒后自动进入下一关（HP 回满）
- 游戏结束时显示最终得分
- 支持同时按下移动和射击
- 支持局域网联机对战（需启动 WebSocket 服务器）

## 技术细节

- 纯 HTML + CSS + JavaScript，零外部依赖
- 基于 Canvas 2D 渲染，60fps 动画循环
- 面向对象设计：Tank、Bullet、Wall、PickupItem 类
- AABB 碰撞检测，支持滑动（sliding）机制避免卡墙
- 关卡程序化生成，支持无限扩展
- RPG 系统模块化独立（`js/rpg.js`），便于扩展

## 本地运行

```bash
# 克隆仓库
git clone https://github.com/cuizhihui987-collab/tank-battle.git
cd tank-battle

# 直接打开（Windows）
start index.html

# 或用任意 HTTP 服务器
python3 -m http.server 3000
# 打开 http://localhost:3000
```
