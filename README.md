# 坦克大战 (Tank Battle)

经典坦克对战游戏的 HTML/Canvas 实现，纯前端，无需任何依赖，打开浏览器即可游玩。

> 可直接打开 `index.html` 在浏览器中运行。

## 操作说明

| 按键 | 功能 |
|------|------|
| **W/A/S/D** 或 **方向键** | 移动坦克 |
| **空格键** | 射击 |
| **P** | 暂停/继续 |
| **重新开始按钮** | 重置游戏 |

## 功能特性

### 核心玩法
- 多关卡设计，每关需消灭全部 10 辆敌方坦克方可进入下一关
- 随关卡提升，敌人生成速度加快，地图布局更复杂
- 玩家拥有 3 条生命，阵亡后会在安全位置重生（带短暂无敌护盾）

### 敌人 AI
- 敌人自主巡逻、追逐玩家
- 60% 概率朝玩家方向移动，40% 概率随机移动
- 智能射击：面朝玩家方向时优先开火
- 碰撞后自动切换方向

### 坦克类型
- **玩家坦克**（绿色）：速度较快，射速高
- **普通敌方坦克**（红色）：标准属性
- **中型敌方坦克**（橙色，Lv2+）：2 点生命值
- **重型敌方坦克**（紫色，Lv3+）：3 点生命值，带血条显示

### 子弹系统
- 玩家子弹速度更快（5px/frame），可弹射墙壁一次
- 敌方子弹速度较慢（3.5px/frame）
- 敌我子弹可对撞抵消
- 子弹带有拖尾特效

### 地图系统
- **砖墙**（红色）：2 点生命值，可被子弹击碎，受损后显示裂纹
- **钢墙**（灰色）：不可摧毁，带铆钉装饰
- 5 种预设关卡布局 + 随机散落墙壁，每关体验不同
- 布局包括：横排墙、方格堡垒、十字阵列、散点网格、钢铁要塞

### 视觉特效
- 爆炸动画（由内向外扩散 + 白色高亮核心）
- 粒子系统（击中墙壁、坦克爆炸、得分等场景）
- 屏幕震动（坦克爆炸时）
- 子弹拖尾光晕
- 坦克履带细节绘制
- 护盾闪烁效果（重生无敌期间）
- 半透明暂停/胜利/失败遮罩

### 其他
- 右上角实时显示分数、剩余敌人数量、生命值
- 关卡通过时显示胜利提示，2 秒后自动进入下一关
- 游戏结束时显示最终得分
- 支持同时按下移动和射击

## 技术细节

- 纯 HTML + CSS + JavaScript，零外部依赖
- 基于 Canvas 2D 渲染，60fps 动画循环
- 面向对象设计：Tank、Bullet、Wall 类
- AABB 碰撞检测，支持滑动（sliding）机制避免卡墙
- 关卡程序化生成，支持无限扩展
